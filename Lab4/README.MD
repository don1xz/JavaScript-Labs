## Шаг 1. Класс `Item`

Класс `Item` представляет базовый предмет инвентаря с полями `name`, `weight`, `rarity` и методами `getInfo()` / `setWeight()`.

## Шаг 2. Класс `Weapon`

Класс `Weapon` расширяет `Item`, добавляя поля `damage` и `durability`, а также методы `use()`, `repair()` и переопределённый `getInfo()`.

## Шаг 3. Тестирование

Созданы объекты `Item` и `Weapon`, вызваны все методы. Проверен пограничный случай: `use()` при `durability = 0` не уходит в минус (`Math.max(0, ...)`).

## Шаг 4. Функции-конструкторы и опциональная цепочка

Классы переписаны через функции-конструкторы (`ItemFn`, `WeaponFn`). Наследование реализовано через `ItemFn.call(this, ...)` и `Object.create(ItemFn.prototype)`. Опциональная цепочка (`?.`) использована для безопасного обращения к свойствам потенциально `null`-значений.

## Ключевые понятия

- **Функция-конструктор** — способ создавать объекты через `new`
- **`?.` (опциональная цепочка)** — защита от ошибок при доступе к данным
- **`prototype`** — объект, из которого наследуют все экземпляры функции-конструктора
