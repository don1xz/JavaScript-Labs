# Лабораторная работа — Учёт транзакций

Веб-приложение на чистом JavaScript для добавления, просмотра и удаления финансовых транзакций.

## Структура проекта

```
transaction-app/
├── index.html
├── style.css
└── src/
    ├── index.js         — точка входа, обработчики событий
    ├── transactions.js  — массив транзакций и функции работы с ним
    ├── ui.js            — отрисовка элементов на странице
    └── utils.js         — вспомогательные функции
```

## Что делает каждый файл

**utils.js** — три вспомогательные функции: генерация уникального ID, форматирование даты в формат ДД.ММ.ГГГГ ЧЧ:ММ, и обрезка описания до первых 4 слов.

**transactions.js** — хранит массив транзакций и три функции: добавить транзакцию, удалить по ID, посчитать итоговую сумму через `reduce`.

**ui.js** — всё что связано с DOM: добавить строку в таблицу, удалить строку, обновить итог, показать детали транзакции.

**index.js** — импортирует всё остальное, слушает события формы и таблицы.

## Как работает приложение

Заполняешь форму (сумма, категория, описание) и нажимаешь "Добавить". Создаётся объект транзакции с уникальным ID и текущей датой, он добавляется в массив и появляется строкой в таблице. Строка зелёная если сумма положительная, красная если отрицательная. В столбце описания показываются только первые 4 слова.

Если кликнуть на строку — внизу появляется полное описание транзакции. Кнопка ✕ удаляет транзакцию из массива и из таблицы. После каждого действия пересчитывается и обновляется итоговая сумма.

## Контрольные вопросы

**1. Как получить доступ к элементу на странице?**

Через методы `document`:

```js
document.getElementById('my-id')
document.querySelector('.my-class')
document.querySelectorAll('tr')
```

В проекте так получаю форму, таблицу, блок с итогом и блок с деталями.

**2. Что такое делегирование событий?**

Это когда вешаешь один обработчик на родительский элемент, а не на каждый дочерний. Событие всплывает вверх по DOM и родитель его перехватывает. Удобно когда элементы добавляются динамически — не нужно каждый раз вешать новый обработчик.

В проекте один обработчик `click` висит на всей таблице. Внутри через `e.target.closest()` определяю — нажали кнопку удаления или просто строку:

```js
table.addEventListener('click', (e) => {
  const btn = e.target.closest('.btn-delete')
  if (btn) { /* удаляем */ }

  const row = e.target.closest('tr[data-id]')
  if (row) { /* показываем детали */ }
})
```

**3. Как изменить содержимое элемента DOM?**

```js
el.textContent = 'новый текст'   // просто текст
el.innerHTML = '<b>текст</b>'   // с HTML-разметкой
el.className = 'positive'       // изменить класс
```

В проекте `renderTotal` меняет `textContent` и `className`, `renderDetail` использует `innerHTML` для вывода информации о транзакции.

**4. Как добавить новый элемент в DOM?**

```js
const row = document.createElement('tr')
row.innerHTML = `<td>Еда</td><td>200 ₽</td>`
tbody.appendChild(row)
```

В проекте так работает функция `renderRow` — создаёт строку и добавляет её в конец таблицы.
