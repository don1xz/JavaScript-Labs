## Описание проекта
**Цель проекта** — разработка интерактивного веб-приложения для управления повседневными задачами ("To-Do List") с использованием чистого JavaScript (Vanilla JS). Проект демонстрирует практические навыки работы с деревом DOM, обработкой пользовательских событий, валидацией форм и манипуляциями с массивами объектов в модульной структуре (ES6+ Modules).

### Основные функции:
1. **Работа с DOM:** Динамическое добавление элементов списка задач в интерфейс и их удаление без перезагрузки страницы.
2. **Валидация:** Проверка поля ввода на пустоту перед добавлением задачи с выводом понятного сообщения об ошибке.
3. **Управление состоянием:** Возможность переключения статуса задачи (выполнено / активно) по клику на текст.
4. **Фильтрация:** Разделение задач на категории «Все», «Активные» и «Выполненные».
5. **Поиск:** Живой поиск по названию задач (фильтрация списка в реальном времени при вводе символов).
6. **Модульность:** Разделение кодовой базы на логический блок работы с данными (`data.js`) и блок управления интерфейсом (`app.js`).

## Инструкции по установке и запуску проекта
Приложение написано на чистом JavaScript и не требует установки сторонних библиотек или сборщиков (npm/webpack).

1. Склонируйте репозиторий проекта с GitHub или скачайте архив с файлами.
2. Поскольку проект использует JavaScript модули (`type="module"`), для корректной работы его необходимо запускать через локальный сервер.
    * **Вариант 1:** Использовать расширение **Live Server** в редакторе VS Code (нажать кнопку "Go Live").
    * **Вариант 2:** Использовать любой локальный сервер (например, через Python: `python -m http.server`).
3. Откройте приложение в браузере по адресу локального хоста (обычно `http://127.0.0.1:5500`).

## Архитектура кода и примеры реализации

Код разделен на модули для обеспечения читаемости и поддерживаемости (принцип Separation of Concerns).

* **`data.js`**: Хранит массив объектов `todos` и экспортирует чистые функции для его изменения: `addTodo()`, `deleteTodo()`, `toggleTodoStatus()`.
* **`app.js`**: Отвечает за подписку на события DOM (клик, ввод текста, отправка формы) и вызывает функцию `render()`, которая синхронизирует состояние массива с HTML-страницей.

### Фрагмент кода валидации и добавления (из `app.js`):
```javascript
todoForm.addEventListener('submit', (event) => {
    event.preventDefault();
    const text = taskInput.value.trim();

    if (text === '') {
        errorText.textContent = 'Поле не может быть пустым!';
        taskInput.style.borderColor = '#e74c3c';
        return;
    }
    
    addTodo(text);
    taskInput.value = '';
    render();
});
